# 全局开发规则

## 语言规范
- 所有回复、代码注释、文档使用中文
- 变量和函数命名使用英文驼峰命名法

## 测试规范
- 运行测试：`npm test`，不需要 `--run` 参数
- 覆盖率目标：Background 90%+，Content 85%+
- 测试文件：`src/模块/__test__/文件名.test.ts`
- 不自动添加测试，除非用户明确要求

## 代码规范
- TypeScript 严格模式，禁止 `any`（除非必要且有注释）
- 所有导出函数和类型必须有中文注释
- 遵循 ESLint 规则

## 工作原则
- 简洁直接，避免冗长总结和项目符号列表
- 并行执行独立操作
- 使用 `getDiagnostics` 检查代码问题

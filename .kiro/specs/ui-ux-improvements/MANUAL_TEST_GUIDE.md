# UI/UX 改进手动测试指南

## 测试环境准备

1. **构建插件**
   ```bash
   npm run build
   ```

2. **加载插件**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 启用"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目的 `build` 目录

3. **准备测试页面**
   - 打开任意包含文本内容的网页（如新闻网站、博客等）
   - 确保页面有足够的文本可供选择

## 测试项目

### ✅ 测试 1：深色主题文字可读性

**目标**：验证深色主题下高级清洗选项文字清晰可读

**步骤**：
1. 在测试页面上选中一段文本
2. 点击插件图标或使用快捷键触发文本提取
3. 在结果面板中点击"高级清洗"按钮
4. 切换系统到深色主题模式：
   - macOS: 系统偏好设置 → 通用 → 外观 → 深色
   - Windows: 设置 → 个性化 → 颜色 → 选择模式 → 深色
5. 观察高级清洗弹窗中的选项文字

**预期结果**：
- ✓ 所有选项文字（如"移除空行"、"合并多行"等）清晰可读
- ✓ 文字颜色与背景有足够对比度（不应该是黑色文字）
- ✓ 标签文字（如"自定义分隔符"）也清晰可读
- ✓ 在浅色主题下文字同样清晰

**验证需求**：需求 2.1, 2.2, 2.3

### ✅ 测试 2：自定义分隔符功能

**目标**：验证自定义分隔符能够正常生效

**重要说明**：
- "合并多行（使用自定义分隔符）"：支持自定义分隔符
- "合并为一行（使用空格分隔）"：固定使用空格，不支持自定义分隔符
- 两个选项互斥，选中一个会自动取消另一个

**测试场景 A：使用自定义分隔符**

**步骤**：
1. 选中包含多行文本的内容
2. 触发文本提取
3. 点击"高级清洗"按钮
4. 勾选"合并多行（使用自定义分隔符）"选项
5. 在"自定义分隔符"输入框中输入 ` | `（空格+竖线+空格）
6. 点击"应用清洗"按钮

**预期结果**：
- ✓ 结果面板中的文本使用 ` | ` 分隔各行
- ✓ 例如："第一行 | 第二行 | 第三行"

**测试场景 B：不提供自定义分隔符**

**步骤**：
1. 选中包含多行文本的内容
2. 触发文本提取
3. 点击"高级清洗"按钮
4. 勾选"合并多行（使用自定义分隔符）"选项
5. 不输入自定义分隔符（保持输入框为空）
6. 点击"应用清洗"按钮

**预期结果**：
- ✓ 结果面板中的文本使用换行符分隔（保持多行格式）
- ✓ 各行文本仍然分行显示

**测试场景 C：合并为一行（使用空格）**

**步骤**：
1. 选中包含多行文本的内容
2. 触发文本提取
3. 点击"高级清洗"按钮
4. 勾选"合并为一行（使用空格分隔）"选项
5. 观察"合并多行"选项自动取消
6. 观察自定义分隔符输入框被禁用（变灰）
7. 点击"应用清洗"按钮

**预期结果**：
- ✓ "合并多行"选项自动取消
- ✓ 自定义分隔符输入框被禁用
- ✓ 结果面板中的文本使用空格分隔，合并为一行
- ✓ 例如："第一行 第二行 第三行"

**测试场景 D：互斥关系验证**

**步骤**：
1. 勾选"合并多行（使用自定义分隔符）"
2. 然后勾选"合并为一行（使用空格分隔）"
3. 观察"合并多行"是否自动取消

**预期结果**：
- ✓ 两个选项互斥，不能同时选中
- ✓ 选中一个会自动取消另一个

**验证需求**：需求 1.1, 1.2, 1.3, 1.4, 3.1, 3.2, 3.3

### ✅ 测试 3：ESC 键逐层关闭多个弹窗

**目标**：验证 ESC 键能够逐层关闭弹窗，而不是一次性关闭所有

**测试场景 A：单层弹窗**

**步骤**：
1. 选中文本并触发提取
2. 在结果面板显示时，按下 ESC 键

**预期结果**：
- ✓ 结果面板关闭
- ✓ 页面恢复正常

**测试场景 B：两层弹窗（结果面板 + 高级清洗弹窗）**

**步骤**：
1. 选中文本并触发提取
2. 点击"高级清洗"按钮打开清洗弹窗
3. 按下第一次 ESC 键
4. 观察哪个弹窗关闭
5. 按下第二次 ESC 键

**预期结果**：
- ✓ 第一次按 ESC：只关闭高级清洗弹窗（最上层）
- ✓ 结果面板仍然显示
- ✓ 第二次按 ESC：关闭结果面板
- ✓ 页面恢复正常

**测试场景 C：三层弹窗（结果面板 + 高级清洗弹窗 + 导出弹窗）**

5. 观察哪个弹窗关闭
6. 按下第二次 ESC 键
7. 按下第三次 ESC 键

**预期结果**：
- ✓ 第一次按 ESC：只关闭导出弹窗（最上层）
- ✓ 高级清洗弹窗和结果面板仍然显示
- ✓ 第二次按 ESC：关闭高级清洗弹窗
- ✓ 结果面板仍然显示
- ✓ 第三次按 ESC：关闭结果面板
- ✓ 页面恢复正常

## 修复说明

### 已修复的问题

1. **✅ 测试2失败** - 改进了文案，明确"合并多行（使用自定义分隔符）"和"合并为一行（使用空格分隔）"的区别
2. **✅ 文案歧义** - 添加了UI互斥逻辑，选中一个选项会自动取消另一个，并禁用/启用自定义分隔符输入框
3. **✅ 测试4失败** - 修复了 URL.createObjectURL 在 service worker 中不可用的问题，改用 FileReader.readAsDataURL
4. **✅ 测试6失败** - 修复了弹窗显示时未禁用文本选择的问题，现在所有弹窗都会禁用页面文本选择

### 技术细节

- **导出功能**：使用 FileReader 将 Blob 转换为 Data URL，兼容 Chrome Extension Service Worker
- **文本选择禁用**：在第一个弹窗显示时禁用，所有弹窗关闭后恢复
- **互斥逻辑**：通过 checkbox change 事件实现，提供即时视觉反馈

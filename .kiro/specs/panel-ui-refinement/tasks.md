# 实施计划：面板 UI 与行为调优

## 概述

本实施计划将设计文档中的修改分解为离散的编码步骤。每个任务都专注于特定的代码修改，确保增量进展。所有修改严格限制在 UI 层面，不涉及业务逻辑重构。

**面板类型说明：**
- **文本预览面板**：通过 `show()` 或 `showAligned()` 显示，包含 textarea 和复制按钮
- **限制面板**：通过 `showLimitReached()` 或 `showProRequired()` 显示，仅包含提示信息

## 任务

- [x] 1. 修复文本预览面板位置计算逻辑（跟随鼠标模式）
  - 在 Panel 类中添加 `adjustPositionForViewport()` 方法
  - 修改 `show()` 方法，在设置位置后调用边界检测
  - 确保面板完整显示在视口内，优先保证底部和右侧可见
  - _需求：1.1, 1.2, 1.3_

- [x] 2. 修改限制面板显示逻辑（强制居中）
  - 修改 `showLimitReached()` 方法，添加 `forceCenter: true` 参数
  - 修改 `showProRequired()` 方法，添加 `forceCenter: true` 参数
  - 修改 `createElement()` 方法，根据 `forceCenter` 参数应用不同的定位逻辑
  - 当 `forceCenter` 为 true 时，添加 CSS 类实现 fixed 居中定位
  - _需求：3.1, 3.2, 3.3_

- [x] 3. 实现限制面板从策略模块读取次数
  - 在 Panel 类中导入 `FREE_POLICY` from `./usage/policy`
  - 修改 `showLimitReached()` 方法，从 `FREE_POLICY.maxPerDay` 读取最大次数
  - 修改 `createElement()` 方法，接收 `usageInfo` 参数
  - 使用 `usageInfo` 动态生成次数显示文本（格式：`(current/max)`）
  - 移除硬编码的 `(20/20)` 文本
  - _需求：4.1, 4.3_

- [x] 4. 在文本预览面板标题区增加免费额度显示并美化样式
  - 在 CSS 中添加 `.browser-selection-copy-panel-usage-info` 样式类
  - 设置较小字号（12px）、较低透明度（0.7）、较轻字重（400）
  - 修改 Panel 类的 `show()` 方法，接收可选的 `usageInfo` 参数
  - 修改 `createElement()` 方法，在文本预览面板标题区添加免费额度显示元素
  - 格式：`剩余 X 次`（X 为 remaining 值）
  - 确保免费额度信息与主标题形成清晰层级
  - _需求：2.1, 2.2, 2.3, 2.4_

- [x] 5. 美化限制面板文本样式
  - 在 CSS 中添加 `.browser-selection-copy-panel-limit-count` 样式类（主提示）
  - 在 CSS 中添加 `.browser-selection-copy-panel-limit-secondary` 样式类（次要说明）
  - 修改 `createElement()` 方法中限制面板的 HTML 结构，应用新样式类
  - 确保主提示和次要说明有明确的视觉层级区分
  - _需求：5.1_

- [x] 6. 添加限制面板强制居中的 CSS 样式
  - 在 `content.css` 中添加 `.browser-selection-copy-panel-force-center` 样式类
  - 使用 `position: fixed`, `left: 50%`, `top: 50%`, `transform: translate(-50%, -50%)`
  - 确保样式优先级足够高（使用 !important）
  - _需求：3.2, 3.3_

- [x] 7. 检查点 - 确保所有测试通过

  - 修改 `calcPanelPosition()` 方法中 'mouse' 模式的逻辑

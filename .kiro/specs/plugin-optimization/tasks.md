# 任务列表：插件优化

## 概述

本任务列表用于实现插件用户体验优化，主要包括框选超限提示优化。实现方案采用在结果面板顶部添加超限提示条的方式，不拦截用户操作，用户仍可查看和复制前5行内容。

## 任务

- [x] 1. 扩展类型定义
  - **描述**：在 `src/shared/types.ts` 中扩展 `ActionResultMessage` 的 `uiData` 接口，添加升级页面 URL 字段
  - **验收标准**：
    - `uiData` 接口包含 `upgradeUrl?: string` 字段
    - 类型定义符合 TypeScript 严格模式
    - 添加中文 JSDoc 注释
  - **文件**：`src/shared/types.ts`
  - **优先级**：P0

- [x] 2. 实现超限提示条组件
  - **描述**：在 `src/content/panel.ts` 中创建 `createLimitBanner()` 方法，用于生成超限提示条 DOM 结构
  - **验收标准**：
    - 创建 `createLimitBanner(limitMessage: string, upgradeUrl?: string): HTMLDivElement` 方法
    - 返回包含提示文案和升级按钮的 DOM 结构
    - 升级按钮点击时在当前标签页打开升级页面
    - 处理 `upgradeUrl` 缺失的情况（使用默认 URL）
    - 处理页面跳转失败的情况（复制链接到剪贴板并显示 Toast）
    - 添加中文 JSDoc 注释
  - **文件**：`src/content/panel.ts`
  - **优先级**：P0
  - **依赖**：任务 1

- [x] 3. 修改结果面板渲染逻辑
  - **描述**：修改 `src/content/panel.ts` 中的 `showResult()` 方法，在检测到超限时在面板顶部插入超限提示条
  - **验收标准**：
    - 检查 `uiData.isLimited` 和 `uiData.limitMessage` 是否存在
    - 如果存在，调用 `createLimitBanner()` 创建提示条
    - 将提示条插入到 `previewWrapper` 的第一个子元素位置
    - 不影响现有的内容显示和复制功能
    - 遵循三层架构原则，不包含业务逻辑判断
  - **文件**：`src/content/panel.ts`
  - **优先级**：P0
  - **依赖**：任务 2

- [ ] 4. 添加 CSS 样式
  - **描述**：在 `src/content/content.css` 中添加超限提示条的样式类，并调整面板宽度
  - **验收标准**：
    - 将面板宽度从 340px 增加到 420px（容纳超限提示条）
    - 添加 `.tabular-extension-panel-limit-banner` 样式（提示条容器）
    - 添加 `.tabular-extension-panel-limit-message` 样式（提示文案）
    - 添加 `.tabular-extension-panel-upgrade-btn` 样式（升级按钮）
    - 添加 `.tabular-extension-panel-upgrade-btn:hover` 样式（悬停效果）
    - 样式符合设计文档规范：
      - 提示条使用渐变色背景和左侧边框
      - 升级按钮使用渐变色背景（#667eea 到 #764ba2）
      - 升级按钮圆角 8px，阴影效果
      - 悬停时按钮放大 1.05 倍，阴影加深
    - 确保在浅色和深色主题下都有良好的可读性

  - **依赖**：任务 3

## 注意事项

1. **严格遵循三层架构**：
   - Content 层只负责 UI 渲染，不包含业务逻辑
   - 所有文案由 Background 层生成
   - 通过消息协议传递数据

2. **测试策略**：
   - 单元测试验证具体示例和边界情况
   - 集成测试验证真实浏览器环境中的表现
   - 属性测试验证通用属性在所有输入下的正确性

3. **样式规范**：
   - 使用 CSS 变量确保主题适配
   - 使用 `transform` 实现动画效果（GPU 加速）
   - 确保在不同分辨率下的显示效果

4. **错误处理**：
   - 处理 `upgradeUrl` 缺失的情况
   - 处理页面跳转失败的情况
   - 提供友好的错误提示

5. **可访问性**：
   - 升级按钮支持键盘导航
   - 确保颜色对比度符合 WCAG AA 标准

# 发布指南

## 打包和发布流程

### 1. 准备发布
```bash
# 运行完整的发布准备流程（包括代码检查、测试和打包）
npm run prepare-release

# 或者分步执行
npm run lint      # 代码风格检查
npm run test      # 运行所有测试
npm run package   # 创建扩展包
```

### 2. 发布到 Chrome Web Store

#### 前置要求
- Google 开发者账号
- 支付 $5 一次性开发者注册费（如果是首次发布）

#### 发布步骤
1. 访问 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole/)
2. 登录 Google 开发者账号
3. 点击"新增项目"
4. 上传生成的 `browser-selection-copy-v1.0.0.zip` 文件
5. 填写商店信息：
   - **应用名称**: 浏览器框选复制插件
   - **描述**: 通过鼠标拖拽创建选择框，智能提取并复制页面文本
   - **分类**: 生产力工具
   - **语言**: 中文（简体）

#### 商店信息模板

**简短描述**:
智能框选复制工具，轻松提取网页文本内容

**详细描述**:
浏览器框选复制插件是一个简洁高效的 Chrome 扩展，帮助用户快速提取网页中的文本内容。

🎯 **主要功能**
• 鼠标拖拽创建选择框
• 智能识别选择区域内的文本
• 按视觉阅读顺序重新排列文本
• 一键复制到剪贴板
• 无需网络权限，本地处理

✨ **特色优势**
• 操作简单：只需拖拽鼠标即可选择
• 智能排序：自动按从上到下、从左到右的顺序排列文本
• 隐私安全：所有处理在本地完成，不发送任何数据
• 轻量级：不依赖外部库，不影响页面性能
• 兼容性强：适用于所有网站

🔧 **使用方法**
1. 安装扩展后，在任意网页上使用
2. 按住鼠标左键并拖拽创建选择框
3. 释放鼠标后自动提取文本
4. 点击复制按钮将文本复制到剪贴板

适用于学术研究、内容整理、文档编写等多种场景。

**关键词**: 文本提取, 复制工具, 网页选择, 生产力, 办公工具

#### 权限说明
- **activeTab**: 在当前标签页中运行，提取页面文本
- **clipboardWrite**: 将提取的文本复制到剪贴板

### 3. 审核和发布

#### 审核时间
- 通常需要 1-3 个工作日
- 首次发布可能需要更长时间

#### 审核要点
- 确保功能描述准确
- 权限使用合理且必要
- 代码质量良好
- 遵守 Chrome Web Store 政策

#### 可能的审核问题
1. **权限过度**: 我们只请求了必要的 activeTab 和 clipboardWrite 权限
2. **功能不明确**: 提供了详细的功能说明和使用方法
3. **代码质量**: 通过了完整的测试套件验证

### 4. 发布后维护

#### 版本更新
1. 修改 `manifest.json` 中的版本号
2. 更新 `package.json` 中的版本号
3. 运行 `npm run prepare-release` 重新打包
4. 在开发者控制台上传新版本

#### 用户反馈处理
- 监控 Chrome Web Store 的用户评价
- 及时回复用户问题
- 根据反馈优化功能

## 故障排除

### 常见问题

**Q: 打包失败，提示缺少文件**
A: 确保先运行 `npm run build` 编译 TypeScript

**Q: ZIP 创建失败**
A: 手动将 `extension-package` 目录中的文件压缩为 ZIP

**Q: 审核被拒，权限问题**
A: 我们只使用了必要权限，可以在审核意见中说明用途

**Q: 扩展在某些网站不工作**
A: 检查网站的 CSP 策略，某些网站可能限制扩展运行

### 调试方法
1. 在 Chrome 中加载未打包的扩展进行测试
2. 使用开发者工具查看控制台错误
3. 检查 `chrome://extensions/` 中的错误信息

## 6. 代码质量

### 6.1 职责分离清晰
✅ **通过**

**Collect 模块**：
- 纯事实采集，不包含业务逻辑
- 使用 TreeWalker 遍历 DOM
- 过滤不可见元素和选择区域外的元素
- 不执行排序或行合并

**Layout 模块**：
- 专注于视觉行分组算法
- 参数化魔法数字（lineThresholdRatio）
- 按 Y 坐标分组，按 X 坐标排序
- 不执行文本拼接

**Format 模块**：
- 专注于文本格式化
- 保留所有防护措施（行数限制、长度限制）
- 在行内插入空格，在行间插入换行符
- 完整的错误处理

**Index 模块**：
- 提供统一的对外接口
- 严格按照 collect → layout → format 顺序执行
- 重新导出必要的类型定义

**验证需求**：2.1-2.10, 3.1-3.9, 4.1-4.6, 5.1-5.5

### 6.2 BrowserSelectionCopy 职责收敛
✅ **通过**

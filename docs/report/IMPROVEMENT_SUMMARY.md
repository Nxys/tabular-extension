## 技术改进详情

### 1. 表格检测算法优化

**问题分析：**
- 原算法使用范围判断（最大值 - 最小值 ≤ 阈值）
- 当列内有较大的 X 坐标偏移时，会将一列识别为多列
- 阈值 30px 对于真实场景来说过小

**解决方案：**

```typescript
// 改进前：使用范围判断
const potentialRange = sorted[i] - clusterStart;
if (potentialRange <= COLUMN_THRESHOLD) {
  // 加入当前聚类
}

// 改进后：使用相邻间距判断
const gap = sorted[i] - sorted[i - 1];
if (gap <= COLUMN_THRESHOLD) {
  // 加入当前聚类
}
```

**效果：**
- 更稳健的列识别
- 正确处理列内的 X 坐标偏移
- 所有属性测试通过（100 次迭代）

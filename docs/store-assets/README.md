# Chrome Web Store 资源文件

## 图标要求

### 扩展图标
- **16x16**: 工具栏小图标
- **32x32**: Windows 系统图标
- **48x48**: 扩展管理页面图标
- **128x128**: Chrome Web Store 和安装时显示

### 商店图标
- **128x128**: 必需，在商店中显示的主图标

## 截图要求

### 尺寸规格
- **1280x800** 或 **640x400** (推荐 1280x800)
- 最多 5 张截图
- PNG 或 JPEG 格式

### 建议截图内容
1. **主要功能演示**: 显示鼠标拖拽创建选择框的过程
2. **文本提取结果**: 展示提取的文本和结果面板
3. **使用场景**: 在实际网页中的使用效果
4. **功能特色**: 突出智能排序和一键复制功能

## 推广图片（可选）

### 小型推广图片
- **440x280**: 在 Chrome Web Store 中显示

### 大型推广图片  
- **1400x560**: 在 Chrome Web Store 精选区域显示

## 图标设计建议

### 设计元素
- 使用选择框/矩形图标
- 结合文本/复制相关元素
- 采用现代扁平化设计风格
- 使用蓝色或绿色主色调（代表生产力工具）

### 图标示例描述
```
主图标：一个虚线矩形选择框，内部有几行文本线条，
右上角有一个小的复制图标，整体采用蓝色渐变背景
```

## 注意事项

1. **图标一致性**: 所有尺寸的图标应保持设计一致性
2. **清晰度**: 确保在小尺寸下图标仍然清晰可辨
3. **品牌识别**: 图标应该能够代表应用的核心功能
4. **截图质量**: 使用高分辨率截图，避免模糊
5. **文字说明**: 截图中可以添加简短的功能说明文字

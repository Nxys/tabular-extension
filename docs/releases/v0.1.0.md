# Tabular v0.1.0

## Highlights

- First public open-source release of the Tabular Chrome extension.
- Drag-select text from web pages and copy content in visual reading order.
- Local-first workflow with no backend dependency.
- Foundation for table detection, alignment, and future CSV export improvements.

## Release Assets

- `tabular-extension-v0.1.0.zip`: unpacked Chrome extension bundle for manual installation

## Installation

1. Download `tabular-extension-v0.1.0.zip` from the release assets.
2. Extract the ZIP file to a local directory.
3. Open `chrome://extensions/` in Chrome.
4. Enable `Developer mode`.
5. Click `Load unpacked`.
6. Select the extracted directory.

## Notes

- The extension runs locally in the browser.
- Current packaging target is Chromium-based browsers with Manifest V3 support.
- A public demo or store listing can be linked as the repository website once available.

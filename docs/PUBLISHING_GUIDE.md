## 🎨 视觉资源准备详解

### 图标要求

#### 扩展图标尺寸
- **16x16**: 工具栏小图标
- **32x32**: Windows 系统图标
- **48x48**: 扩展管理页面图标
- **128x128**: Chrome Web Store 和安装时显示（必需）

#### 图标设计建议
**设计元素**：
- 使用选择框/矩形图标
- 结合文本/复制相关元素
- 采用现代扁平化设计风格
- 使用紫色渐变主色调（与扩展风格一致）

**图标示例描述**：
```
主图标：一个虚线矩形选择框，内部有几行文本线条，
右上角有一个小的复制图标，整体采用紫色渐变背景
```

#### 创建工具推荐

**在线工具**：
- Canva
- Figma
- Adobe Express

**专业软件**：
- Adobe Illustrator
- Sketch
- Photoshop

**免费工具**：
- GIMP
- Inkscape
- Paint.NET

### 截图要求

#### 尺寸规格
- **1280x800** 或 **640x400** (推荐 1280x800)
- 最多 5 张截图
- PNG 或 JPEG 格式

#### 建议截图内容
1. **主要功能演示**: 显示鼠标拖拽创建选择框的过程（紫色渐变虚线边框）
2. **文本提取结果**: 展示提取的文本和结果面板
3. **使用场景**: 在实际网页中的使用效果
4. **功能特色**: 突出智能排序和一键复制功能
5. **主题切换**: 展示浅色/深色模式自动适配

### 推广图片（可选）

#### 小型推广图片
- **440x280**: 在 Chrome Web Store 中显示

#### 大型推广图片
- **1400x560**: 在 Chrome Web Store 精选区域显示

### 文件命名规范

```
icons/
├── icon-16.png
├── icon-32.png
├── icon-48.png
└── icon-128.png

screenshots/
├── screenshot-1-main-feature.png
├── screenshot-2-text-extraction.png
├── screenshot-3-use-case.png
├── screenshot-4-result-panel.png
└── screenshot-5-theme-switching.png

promotional/
├── small-promo-440x280.png
└── large-promo-1400x560.png
```

### 注意事项

1. **图标一致性**: 所有尺寸的图标应保持设计一致性
2. **清晰度**: 确保在小尺寸下图标仍然清晰可辨
3. **品牌识别**: 图标应该能够代表应用的核心功能
4. **截图质量**: 使用高分辨率截图，避免模糊
5. **文字说明**: 截图中可以添加简短的功能说明文字

## 🚀 发布步骤

### 1. 完成视觉资源
```bash
# 打开图标生成器
open src/images/icon.html

# 下载生成的图标到 src/images/ 目录
# 重新打包包含图标的版本
npm run package
```

### 2. 创建截图
使用浏览器开发者工具或截图工具，在实际网页上演示扩展功能：
1. **主功能演示**: 在网页上拖拽创建选择框
2. **文本提取**: 显示提取结果和复制按钮
3. **实际使用**: 在真实网站上的使用效果

### 3. 上传到 Chrome Web Store
1. 访问 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole/)
2. 上传 `tabular-extension-v1.0.0.zip`
3. 填写商店信息
4. 上传截图和图标
5. 提交审核

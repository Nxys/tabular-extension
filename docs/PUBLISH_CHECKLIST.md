## 🚀 发布步骤

### 1. 完成视觉资源
```bash
# 打开图标生成器
open create-icons.html

# 下载生成的图标到 icons/ 目录
# 重新打包包含图标的版本
npm run package
```

### 2. 创建截图
建议截图内容：
1. **主功能演示**: 在网页上拖拽创建选择框
2. **文本提取**: 显示提取结果和复制按钮
3. **实际使用**: 在真实网站上的使用效果

### 3. 上传到 Chrome Web Store
1. 访问 [Chrome Web Store 开发者控制台](https://chrome.google.com/webstore/devconsole/)
2. 上传 `browser-selection-copy-v1.0.0.zip`
3. 填写商店信息
4. 上传截图和图标
5. 提交审核
